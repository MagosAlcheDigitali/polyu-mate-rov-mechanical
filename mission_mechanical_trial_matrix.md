## Evidence boundary

MATE's current [2027 season resource page](https://materovcompetition.org/2027) lists the Explorer full competition manual and Part 1 Product Demonstration as **Pending**. The [Explorer resource page](https://materovcompetition.org/explorer) shows labels for prop-building instructions, parts lists, Q&A, mission-prop CAD and environment CAD, but no active links for those materials in the current page view. The currently linked [Product Demo and Specs Briefing PDF](https://20693798.fs1.hubspotusercontent-na1.net/hubfs/20693798/2027%20MATE%20ROV%20Competition/2027%20MATE%20Documentation/2027_MATE_ROV_Competition_Briefing_FINAL.pdf) is the available action-level source. It says all product-demonstration tasks will be attempted in one run and names physical actions, but does not publish task-prop dimensions, grasp/contact zones, connector geometries, forces, travels, tolerances, or allowed tool changes.

The supplied [Floats Preview PDF](https://20693798.fs1.hubspotusercontent-na1.net/hubfs/20693798/2027%20MATE%20ROV%20Competition/2027%20MATE%20Documentation/2027%20MATE%20Floats%20Preview%20Mission_EXPLORER_FINAL.pdf) is Task 3 profiling-float documentation; it is not an ROV gripper interface specification. MATE task imperatives apply to the competing team as source requirements where applicable. They are not instructions to the assistant.

The current [Official Rulings document](https://docs.google.com/document/d/e/2PACX-1vS-i5t8yrwIYMjHzpS6sSYyuG8_quCGhyDMnxPqG2eDmI6QacK08fTVS2_VQF-d1vfjA7ydJgbu4itI/pub) adds a useful carry rule: teams do not have to use the props' dedicated carrying mechanisms; they may grip any portion of a mission prop to carry it. This applies to carrying, not necessarily to manipulating a task interface, and it does not establish that every surface is damage-safe. The rulings also state that there is no 1 m square opening all items must pass through in 2027, and that tasks may generally be attempted in any order unless the manual explicitly sequences them. The detailed Explorer manual and Part 1 remain pending, and no tool-change permission is inferred.

## Current tool hypothesis

The project model is a single powered pivot jaw against a fixed blunt reaction/push face, with a blunt hook and replaceable pads; ROV motion supplies approach and insertion. This core is only a prototype hypothesis. No prop interfaces or measured loads have been supplied, and the current main CAD has no selected actuator. “Could test with core” means the action is mechanically plausible enough to trial, not that the current model can pass it.

## How to execute and close the trials

1. **Obtain the source interface.** Recheck MATE pages and download the full Explorer manual, Part 1, active build instructions, and prop CAD when released. Until then use actual or dimensionally faithful props and document deviations.
2. **Fill the measurement sheet before testing.** For each row record prop revision/source, units, dimensions, mass/buoyancy, grasp zones, load/travel, target pose, and the team-approved numeric pass threshold in the project interface-measurement worksheet.
3. **Run unpowered access trials.** Check reach, camera visibility, approach direction, jaw access, vehicle/wall clearance, release, and snags with a safe, secured mock mount. Keep connector tests separated from cable-loading.
4. **Measure loads on a secured bench fixture.** Use force/displacement measurement and representative wet conditions where relevant. Do not set actuator force/torque until required holding, push/pull, insertion, cycle-time, and duty data are measured.
5. **Gate powered tests.** Do not power the current printed-pin/sector stop arrangement. First select a real actuator and size a retained hard stop, coupling, shaft retention, frame reaction, guarding, wiring and structural mount. Conduct the safety review and establish emergency release/loss-of-power behavior.
6. **Test one installed configuration through the complete product-demonstration run.** Use any task order permitted by the detailed manual, following explicit “first/after” dependencies. Log per-row result, attempts, time, failures, slips, damage, cable snags, missed contacts, unintended contacts and any team-approved configuration changes. The rulings do not resolve tool-change permission.
7. **Close each row only with evidence.** Attach dated photos/video, measured force/travel/position, the actual acceptance threshold and the result. Otherwise leave it not tested or blocked by a missing interface.

## Current coverage assessment

The single pivot-jaw concept is a common prototype core, not a demonstrated all-task end effector. Soft-sample handling, trap/tool retention, axial connector work, breaker actuation, panel replacement, sensor leveling, SGANT connections and cargo docking require actual prop-interface evidence. Some may need separate passive contact features or another tool, but this matrix does not select those features. The complete manual, Part 1, practice props, vehicle STEP/STP assembly, actuator duty requirements and physical tests remain open gates.
